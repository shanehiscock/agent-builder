# Agent builder

Reusable MAPS prompting, task-specific agent design, and workflow handoffs for Shane.

Start with [the project guide](AI%20Context/projects/agent%20builder/README.md) and [chat handoff](AI%20Context/projects/agent%20builder/chat-handoff.md).

## Use on a laptop

Once the private GitHub repository exists and these files are pushed, clone `https://github.com/shanehiscock/agent-builder.git` or open it through Codex's GitHub repository selector. Open the checkout as the project and ask: “Use the agent builder to help me with [task].” Pull committed updates before continuing on another computer; commit and push reviewed changes before switching devices.

Git carries files and committed context, not the original chat history, credentials, live processes, or tool connections. This handoff summarizes the relevant conversation; it is not a verbatim export.

## Cloud environment

This instruction-only project needs no dependency installation and no service startup. Select the repository in a Codex cloud environment after it exists. Review and publish that environment through the product. The current chat cannot be converted into a new cloud project merely by creating a Git repository.

The receptionist, website, and business source remain in `shanehiscock/hiscock-automations`. Attach that repository separately for implementation work. Follow its current instructions and validation commands.
